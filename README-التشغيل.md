# سجل الميدان — نظام جرد شقق الأطباء

هذه الحزمة تحتوي على مشروع نظام جرد عربي متجاوب مع الهاتف، ويعمل دون قاعدة بيانات أو خادم خلفي. يحفظ النظام البيانات تلقائياً داخل متصفح الجهاز باستخدام LocalStorage، مع إمكانية تصدير نسخة احتياطية بصيغة JSON واستيرادها لاحقاً.

## التشغيل للمطور أو على الكمبيوتر

بعد تثبيت Node.js، افتح الطرفية داخل مجلد المشروع ثم نفّذ:

```bash
pnpm install
pnpm dev
```

بعد ذلك افتح الرابط الذي يظهر في الطرفية.

## الرفع على استضافة ثابتة

مجلد `dist/public` هو النسخة الجاهزة للرفع على أي استضافة ملفات ثابتة. ارفع محتوياته كما هي، ثم افتح رابط الموقع من الهاتف ويمكنك تثبيته على الشاشة الرئيسية إذا كان المتصفح يدعم PWA.

## الاستخدام

أضف الشقق أولاً، ثم أضف أي قطعة أو جهاز يدوياً واربطه بالشقة المناسبة. استخدم البحث والتصفية للوصول السريع للسجلات. من الإعدادات يمكنك تغيير اسم المبنى، تصدير نسخة JSON احتياطية، أو استيراد ملف سابق.

## الطباعة

من زر **معاينة الطباعة** اختر الطابعة أو الحفظ كـ PDF، ثم تأكد من اختيار ورق **A4**. النظام يجهز نموذجاً رسمياً يتضمن بيانات المبنى والشقة والقطع والحالات والملاحظات والتوقيعات.

## تنبيه مهم

الحفظ المحلي مرتبط بالمتصفح والجهاز المستخدم. احتفظ بنسخة JSON دورية، خصوصاً قبل حذف بيانات المتصفح أو تغيير الهاتف.
