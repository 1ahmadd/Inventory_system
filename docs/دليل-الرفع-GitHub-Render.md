# دليل الرفع إلى GitHub والربط بمنصة Render

## 1) رفع المشروع إلى GitHub

```bash
# داخل مجلد المشروع بعد فك الضغط
git init
git add .
git commit -m "نظام سجل الميدان مع الدخول الآمن وPWA"
git branch -M main

# أنشئ مستودعاً جديداً من github.com (New Repository) ثم:
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

> ملاحظة: ملف `server/data/` (المستخدمون والجلسات) مستبعد في `.gitignore` ولا يُرفع إلى GitHub — يُنشأ تلقائياً على الخادم عند أول تشغيل.

## 2) النشر على Render

1. ادخل إلى https://render.com وسجّل بحساب GitHub.
2. اضغط **New +** ثم **Web Service** واختر المستودع.
3. الإعدادات:
   - **Runtime:** Node
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Plan:** Free (يكفي للتشغيل)
4. من تبويب **Environment** أضف متغيرات البيئة التالية:

| المتغير | القيمة | الوظيفة |
|---|---|---|
| `NODE_ENV` | `production` | وضع الإنتاج |
| `SMTP_USER` | بريد Gmail المُرسِل (مثلاً a77ahmadd@gmail.com) | حساب إرسال رموز التأكيد |
| `SMTP_PASS` | كلمة مرور التطبيق App Password | مصادقة Gmail |
| `OTP_EMAIL` | `a77ahmadd@gmail.com` | البريد المستلم لرمز التأكيد (افتراضي نفس القيمة) |
| `ADMIN_USERNAME` | `admin` (اختياري) | اسم مستخدم المدير الافتراضي |
| `ADMIN_PASSWORD` | `Ahmed@2026` (اختياري — غيّره لقيمة أقوى) | كلمة مرور المدير الافتراضي |

5. اضغط **Create Web Service** وانتظر انتهاء البناء، ثم افتح الرابط الذي تعطيه Render.

## 3) تفعيل إرسال رمز التأكيد عبر Gmail (إلزامي لاستلام الرمز على a77ahmadd@gmail.com)

1. من حساب Gmail المُرسِل فعّل **التحقق بخطوتين** من: myaccount.google.com/security
2. بعد التفعيل ستظهر صفحة **كلمات مرور التطبيقات** (App Passwords) على الرابط: https://myaccount.google.com/apppasswords
3. أنشئ كلمة مرور تطبيق باسم «سجل الميدان» وانسخ الرمز المكوّن من 16 خانة.
4. ضع البريد في `SMTP_USER` وكلمة مرور التطبيق (بدون مسافات) في `SMTP_PASS` على Render ثم **Save** — سيعاد النشر تلقائياً.

> بدون إعداد SMTP سيعمل تسجيل الدخول في «وضع التجربة»: يظهر رمز التأكيد داخل واجهة الدخول مباشرة. عند إعداد SMTP يُرسل الرمز حصرياً إلى البريد المعتمد.

## 4) التثبيت كتطبيق على الجوال (PWA)

- **أندرويد (Chrome):** افتح رابط الموقع → قائمة ⋮ → «إضافة إلى الشاشة الرئيسية» / «تثبيت التطبيق».
- **آيفون (Safari):** افتح الرابط → زر المشاركة → «إضافة إلى الشاشة الرئيسية».

## 5) بيانات الدخول الافتراضية

| الحقل | القيمة |
|---|---|
| اسم المستخدم | `admin` |
| كلمة المرور | `Ahmed@2026` |
| رمز التأكيد | يُرسل إلى a77ahmadd@gmail.com |

> غيّر كلمة المرور فور أول دخول من واجهة «المستخدمون».
